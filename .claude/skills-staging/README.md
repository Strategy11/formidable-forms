# skills-staging

Staging copies of Nathanael's personal Claude skills — **not** plugin code and
**not** active project skills. The directory name is deliberately not
`.claude/skills/`, so nothing here loads automatically for anyone working in
this repo.

These are here only so the edits survive an ephemeral session container. The
durable copies live in the personal skill store and are updated by uploading the
delivered bundle through the Skills interface, then verifying the sentinel line
in a fresh chat (see the `skill-save-verification` skill).

Safe to delete once the upload is verified.
